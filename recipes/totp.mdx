| Status | Meaning |
| --- | --- |
| **420** | Invalid code |
| **428** | 2FA required (including some stablecoin withdrawals) |

**On withdrawals and other protected REST calls**, send headers `x-totp` (6 digits) and `x-totp-type`. For **subaccounts**, type is always `gauth` (not SMS or email).

**Enroll** is a different contract (JSON body, not those headers):

1. `POST /v1/account/subaccount/sfa` with `{ "subaccountUserId": "<uuid>" }` — returns secret / QR.
2. `PUT /v1/account/subaccount/sfa` with `{ "subaccountUserId": "<uuid>", "totp": "<code>" }`.

Parent enroll is `POST /v1/account/settings/sfa` then `PUT /v1/account/settings/sfa` with `totp` in the JSON body.

Fresh codes only. Clock skew on the authenticator causes 420.
