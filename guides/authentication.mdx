Private endpoints on `https://gateway.bit2me.com` require an API key and an HMAC signature. Never share a key. If you suspect a leak, revoke it immediately.

<Warning>
If requests fail with 401, sync the machine clock with NTP first. The documented nonce window is 5 seconds of clock skew. Check [status.bit2me.com](https://status.bit2me.com) before you assume a platform outage. If this persists, [open a support ticket](https://support.bit2me.com/en/support/tickets/new).
</Warning>

## Headers

| Header | Required | Description |
| --- | --- | --- |
| `x-api-key` / `X-API-KEY` | Yes (private) | Public API key |
| `x-nonce` | Yes (signed) | Unix time in **milliseconds** (`Date.now()`). Clock-skew window: **5 seconds** |
| `api-signature` | Yes (signed) | HMAC described below |
| `X-SUBACCOUNT-ID` | When acting for an end user | Subaccount `userId`. HTTP names are case-insensitive; samples use this spelling |
| `x-totp` | Sensitive operations | 6-digit 2FA code |
| `x-totp-type` | With `x-totp` | `gauth`, `sms`, or `email`. **Always `gauth` for subaccounts** |

Validate the server TLS certificate and abort if validation fails.

## HMAC algorithm

1. Build the message:
   - No body: `{nonce}:{path}`
   - JSON body: `{nonce}:{path}:{compactJson}`
2. SHA-256 the message (binary digest).
3. HMAC-SHA512 using your **secret**, over that digest.
4. Base64-encode the HMAC. That value is `api-signature`.

The body used to sign **must** be the exact request body string:

- JavaScript: `JSON.stringify(body)` (no spaces).
- Python: `json.dumps(body, separators=(",", ":"))`.

Do not mix pretty-printed JSON into the signature.

<CodeGroup>
```javascript Node.js
const crypto = require("crypto");

function getClientMessageToSign(nonce, url, body) {
  const hasBody = !!body;
  return hasBody ? `${nonce}:${url}:${JSON.stringify(body)}` : `${nonce}:${url}`;
}

function getMessageSignature(message, secret) {
  const hashDigest = crypto.createHash("sha256").update(message).digest("binary");
  return crypto.createHmac("sha512", secret).update(hashDigest, "binary").digest("base64");
}

const nonce = Date.now();
const path = "/v1/trading/wallet/balance";
const signature = getMessageSignature(getClientMessageToSign(nonce, path), process.env.BIT2ME_API_SECRET);
```

```python Python
import hashlib, hmac, json, base64

def sign(nonce: str, path: str, secret: str, body=None) -> str:
    if body is None:
        message = f"{nonce}:{path}".encode()
    else:
        compact = json.dumps(body, separators=(",", ":"))
        message = f"{nonce}:{path}:{compact}".encode()
    digest = hashlib.sha256(message).digest()
    return base64.b64encode(hmac.new(secret.encode(), digest, hashlib.sha512).digest()).decode()
```

```bash cURL
# Replace SIGNATURE after computing HMAC locally.
curl -sS "https://gateway.bit2me.com/v1/trading/wallet/balance" \
  -H "x-api-key: $BIT2ME_API_KEY" \
  -H "api-signature: $SIGNATURE" \
  -H "x-nonce: $NONCE"
```
</CodeGroup>

## TOTP

Some operations require 2FA:

- `x-totp` — code
- `x-totp-type` — `gauth` \| `sms` \| `email`

For **subaccount** operations, `x-totp-type` is always `gauth`.

Enroll subaccount 2FA with `POST /v1/account/subaccount/sfa` then `PUT /v1/account/subaccount/sfa`. Parent path `POST /v1/account/settings/sfa` is a different account. Details: [2FA 420 and 428](/recipes/totp).

## Playground

Mintlify cannot compute this HMAC in the interactive playground. REST pages on this site use **copyable** examples. Sign locally, then send the request from your backend.

## Key scopes

When you create a key you can request:

- **Read**
- **Trade** — create or cancel orders
- **Withdraw** — withdrawals that bypass two-factor authentication

Prefer IP allowlists on Trade and Withdraw keys.

## Gateway WebSocket

REST HMAC does not sign the notification socket. After `open` on `wss://${host}:${port}/` (host from Scalar / your integration manager):

- JWT: `POST /v1/signin/apikey` (HMAC) → send `{ "type": "authenticate", "payload": { "token": "<accessToken.token>" } }`
- Or API key: `{ "type": "authenticate", "payload": { "apikey": ["<api-key>"] } }`

Failed auth closes the socket with **4000**. Full examples: [Gateway notifications](/wallet/websocket).

Pro Trading uses a **different** URL and envelope (`event: authenticate` + REST token, 1 minute). See [Pro WebSocket](/pro/websocket).
