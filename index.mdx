## Start here

<Steps>
  <Step title="Create API keys">
    Generate keys in the [Bit2Me API dashboard](https://account.bit2me.com/api-keys). Copy the key **and** the secret. There is no sandbox host. Use the smallest scope you need (Read, Trade, Withdraw) and restrict by IP when you can.
  </Step>
  <Step title="Sign your first request">
    Private endpoints use HMAC. Follow [Authentication](/guides/authentication) and send `x-api-key`, `api-signature`, and `x-nonce`.
  </Step>
  <Step title="Pick a product">
    Wallet buy/sell, Pro orders, or partner onboarding. The REST tabs are generated from the public OpenAPI specs.
  </Step>
</Steps>
