---
title: "Earn"
description: "Staking positions, rewards, and movements on the Wallet API."
---

Earn (staking) lives on the gateway. List wallets with `GET /v2/earn/wallets`. Other reads still use `/v1/earn/…` as listed below. REST pages are generated from the Wallet OpenAPI snapshot.

Typical reads:

| Call | Use |
| --- | --- |
| `GET /v2/earn/wallets` | List Earn wallets |
| `GET /v1/earn/summary` | Aggregated rewards |
| `GET /v1/earn/wallets/{walletId}` | One Earn wallet |
| `GET /v1/earn/wallets/{walletId}/movements` | Movement history |
| `GET /v1/earn/wallets/rewards/config` | Global rewards config |
| `POST /v1/earn/movements` | Create an Earn movement (deposit/withdraw as documented in the spec) |

Use the [REST reference](/wallet/rest-overview) for request bodies. Do not invent APY figures here.

Internal Wallet ↔ Earn transfers are supported.
