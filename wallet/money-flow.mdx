The public Money Flow spec is a diagram pack, not a REST catalog. Use this page as a map; the live numbers always come from pockets, Pro balances, and teller orders.

```mermaid
flowchart LR
  Fiat[Fiat in — bank, card, Apple Pay, Google Pay, PIX]
  Wallet[Wallet pockets]
  Pro[Pro Trading]
  Earn[Earn]
  Loan[Loans]
  Out[Crypto out — address book or Wallet legacy]
  Fiat --> Wallet
  Wallet --> Pro
  Pro --> Wallet
  Wallet --> Earn
  Earn --> Wallet
  Wallet --> Loan
  Wallet --> Out
```

| Rail | Guide |
| --- | --- |
| Fiat deposit | [Fiat funding](/partner/fiat), [Apple Pay / Google Pay](/partner/apple-google-pay) |
| Buy / sell | [Buy, sell, and swap](/wallet/buy-sell) |
| Spot orders | [First order](/pro/first-order) |
