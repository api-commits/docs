Pro is Bit2Me spot trading: markets, order book, OHLCV, orders, trades, balances, and working capital.

<Info>
Check [status.bit2me.com](https://status.bit2me.com) before you debug a timeout or 5xx. If the platform is healthy and the error persists, [open a support ticket](https://support.bit2me.com).
</Info>

Official samples: [https://github.com/bit2me-devs/trading-spot-samples](https://github.com/bit2me-devs/trading-spot-samples) (`node/auth`, `node/rest/{market-data,trading,funding,ws-auth}`, `node/ws/{public,private}`).

`bit2me-api-node-tool` is discontinued — historical HMAC helper only.

API keys: [Get API keys](https://account.bit2me.com/api-keys). Use **Trade** scope to create or cancel orders. Market data GETs do not require a key.
