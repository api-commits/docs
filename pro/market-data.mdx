Pro market data is public REST. You do not need an API key for these GETs. Server: `https://gateway.bit2me.com`.

| Need | Call |
| --- | --- |
| Markets | `GET /v1/trading/market-config` |
| OHLCV | `GET /v1/trading/candle` |
| Order book | `GET /v2/trading/order-book` |
| Tickers / last trades | MarketData tag in the [Pro REST](/pro/rest-overview) reference |

Official sample: [get-ohlcv](https://github.com/bit2me-devs/trading-spot-samples/blob/main/node/rest/market-data/get-ohlcv).

<Info>
Check [status.bit2me.com](https://status.bit2me.com) before you debug empty candles or 5xx. If the platform is healthy and this persists, [open a support ticket](https://support.bit2me.com).
</Info>

## Candle intervals (Pro)

`GET /v1/trading/candle` requires `symbol`, `interval`, `startTime`, `endTime`, and `limit`. OpenAPI `interval` is **minutes**:

| `interval` | Meaning |
| --- | --- |
| `1` | 1 minute |
| `5` | 5 minutes |
| `15` | 15 minutes |
| `30` | 30 minutes |
| `60` | 1 hour |
| `240` | 4 hours |
| `1440` | 1 day |

The last entry in the array is the **current** (in-progress) candle. OpenAPI documents `limit` with a maximum of **1000**.

## Historical window (720 candles)

Historicals return **720 candles** per request. Size `startTime` / `endTime` (and `limit`) around that. The span you cover is `720 × interval`.

For Pro minute intervals:

| If you choose `interval`… | The 720-candle window is about… |
| --- | --- |
| `60` (1 hour) | 30 days (720 hours) |
| `1440` (1 day) | ~2 years (720 days) |
| `240` (4 hours) | 120 days |
| `30` | 15 days |
| `15` | 7.5 days |
| `5` | 2.5 days |
| `1` | 12 hours |

Named Wallet Market intervals (`one_hour`, `one_day`, `one_week`, `one_month`, `one_year` on currency ticker queries) use the same **720-point** rule:

| If you choose the interval… | The 720-point window is about… |
| --- | --- |
| `one_hour` (1 hour) | 30 days (720 hours / 24) |
| `one_day` (1 day) | ~2 years (720 days) |
| `one_week` (1 week) | ~13.8 years (720 weeks). The theoretical span is not useful in practice. |
| `one_month` (1 month) | 60 years (720 months). The theoretical span is not useful in practice. |
| `one_year` (1 year) | 720 years. The theoretical span is not useful in practice. |

Do not invent extra caps or sunset dates. If you need a longer history than one 720-candle page, page with a new `startTime` / `endTime` on the next window.

## Live book and trades

For a streaming book and public prints, use [Pro WebSocket public channels](/pro/websocket-public) (`order-book`, `public-trades`). REST candles are for history and charts.
