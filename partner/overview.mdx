## Rules that prevent tickets

- One end user = one subaccount. Send `X-SUBACCOUNT-ID` after create.
- Do not treat the user as live until KYC `status: verified` and `tier: 2` (persons).
- Do not call identity init on `type: company`.
- The first time a subaccount sends crypto to a new blockchain address, [verify that destination](/partner/withdrawals-address-book) with 2FA before you withdraw. Later sends to the same `addressBookId` reuse it.
- Complete [Travel Rule](/partner/travel-rule) on **every** on-chain withdrawal (`pending-user-information`). Do not use Embed `report` for this.
- Pay another Bit2Me user with [Social Pay](/partner/transfers) (`email` / `phone` / `alias`). Local last mile is Argentina only.
- Convert EUR/crypto on Pro: [First order](/pro/first-order) documents Wallet deposit and withdraw.
- There is no sandbox API host. Use production gateway URLs and [Get API keys](https://account.bit2me.com/api-keys).
- Apple Pay must leave the in-app WebView.
